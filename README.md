## Documentation Rules

- Business strategy belongs in `docs/business/`.
- Product requirements, roadmap, and feature specs belong in `docs/product/`.
- Architecture, API, data model, deployment, and security docs belong in `docs/technical/`.
- Competitor research and market updates belong in `docs/market/`.
- SOPs, checklists, and agent workflows belong in `docs/delivery/`.
- Root-level files should stay minimal: `README.md`, runtime folders, and project-level config only.
