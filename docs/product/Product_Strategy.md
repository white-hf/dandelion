# 产品战略文档 (Product Strategy)

**文档版本:** 3.0 (The AI Website Factory Pivot)
**编写日期:** 2026-05-17
**最近更新日期:** 2026-05-21
**产品定位:** 面向“有好评但无网站”本地小企业的 AI 专业网站生成工场
**商业模式:** 低门槛 Setup Fee + 每月订阅 (SaaS-like pricing)
**核心价值:** 把本地商家的真实口碑，自动转化成专业、可接单的网站。

---

## 1. 核心战略重构 (The V3.0 Pivot)

我们彻底放弃与传统建站公司和 SEO 公司去争夺“已经有网站”的成熟客户。作为一个以 AI 为核心竞争力的一人公司，我们的主战场是 **“从 0 到 1”的蓝海市场**。

### 1.1 目标市场洞察
在 Google Maps 上存在大量这样的本地服务商（如清洁、水电、除草）：
1.  **服务质量极高：** 拥有 30-50+ 条真实五星评价，证明了其业务能力。
2.  **数字化程度极低：** 没有网站，或者只有 Facebook 主页。
3.  **老板极度忙碌：** 没有时间、技术能力或高额预算（$3000+）去跟建站公司拉扯需求。

### 1.2 我们的颠覆性打法：Show, Don't Tell
传统建站销售：费力解释价值 -> 客户想象不出 -> 嫌贵拒绝。
**Dandelion 的 AI 销售闭环：**
1.  **AI 自动发现：** 爬取 Google Maps，找出高评分、无网站的目标。
2.  **AI 自动生成：** 抓取其真实的 Review、照片、服务区域，匹配我们的高转化 UI 模板（Warm Operator Studio），秒级生成一个专属 Demo 站。
3.  **自动部署与邮件营销：** 将 Demo 部署至临时域名，自动发邮件：“我们用您的好评做了一个网站，点击即可预览。”
4.  **低阻力成交：** 客户看到成品，直接支付低门槛的 Setup Fee（如 $199-$299）并绑定域名，按月（$49-$79）支付系统维护费。

## 2. 产品本质：AI Website Factory

Dandelion 不是一个建站工具，而是一座**“基于真实口碑资产的 AI 本地商家网站工厂”**。

它不要求客户从零写文案或画逻辑，而是最大化利用客户现有的核心资产：**真实评价、真实照片、真实服务区域。**

### 2.1 交付的网站形态 (Standardized Product)
我们不提供无底线的深度定制，只交付高度标准化的“转化机器”：
*   1 个专业首页（融合 Hero、服务介绍、高光 Review）。
*   1 套转化表单（使用我们现有的 I0.6.1 动态表单引擎）。
*   轻量级的后台（只用于查看线索和接收通知）。
*   全站移动端自适应与基础 SEO。

### 2.2 一人公司的可行性
这套模式极大降低了“沟通成本”。人不需要参与重复的“排版”和“催要素材”工作。AI 负责寻找客户、生成内容、自动化部署，创始人只需负责最终审查和客户打款。

## 3. 价格与商业策略

对于没有网站的小企业，初始预算通常有限。我们的策略是**低门槛切入，靠 LTV (生命周期价值) 盈利**。

*   **冷启动特惠 (First 10):** $199 Setup + $49/month
*   **标准版 (Starter):** $299 Setup + $49/month
*   **增长版 (Growth - 包含 AI 自动响应等高级跟进):** $499 Setup + $79/month

**商业逻辑：** 客户花 \$199 买到了一个立即能让他显得极度专业的网络门面，而我们通过代码复用和 AI 生成，极大地压缩了单客成本。

---

## 4. 合规与伦理边界 (Red Lines)

由于业务严重依赖公开数据抓取和自动化发信，必须严格遵守以下红线：
1.  **绝不冒充：** 生成的 Demo 站必须有极其清晰的 `Unofficial Preview` 或 `Generated by Dandelion AI` 的横幅。
2.  **数据授权：** 客户付款上线前，必须在后台显式签署授权协议，允许我们使用其 Google 上的商标、照片和评价。
3.  **合法合规爬取：** 遵守相关平台规则，不违规使用私有数据。
4.  **反垃圾邮件 (Anti-Spam)：** 自动化邮件必须高度个性化，且提供明确的一键退订链接，严格遵守 CAN-SPAM / CASL 法规。

## 5. 下一步行动计划 (Actionable Roadmap)

为了支撑这个全新的 GTM 战略，产品研发必须向 **自动化与 AI 生成** 倾斜：

1.  **[工具链] AI Prospecting Script:** 开发能从 Google Places API 抓取符合“高分+无站”条件商家名单的脚本。
2.  **[核心引擎] Review Intelligence Parser:** 开发 AI Agent，将商家的几十条 Review 自动分类并提取为具有销售力的文案（如提取出“准时”、“不乱收费”作为网站的 Core Values）。
3.  **[前端] Preview Banner Component:** 为生成的网站开发一个全局悬浮的 Demo 提示条，集成“点击购买此站点”的 Checkout 流程。
