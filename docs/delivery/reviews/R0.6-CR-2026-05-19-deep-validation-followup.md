## 3. Findings

### P1-1 `checkbox` 类型未做后端校验

证据：

测试 schema：

```json
{
  "fields": [
    {"name": "agree", "type": "checkbox", "required": false}
  ]
}
```

提交：

```json
{
  "data": {
    "agree": "not_bool"
  }
}
```

实际结果：

```text
valid_with_non_bool_checkbox 200
```

影响：

- `FormFieldConfig.type` 已声明支持 `checkbox`。
- 后端现在会接受非布尔值写入 `leads.custom_fields`。
- 这与上一轮 review 对动态字段校验的要求不一致：checkbox 至少应校验 boolean。

修复要求：

- 当 `type == "checkbox"` 时，只接受 JSON boolean。
- 如果未来需要 checkbox group，应单独定义 `type == "checkbox_group"` 并要求 list，不能混用单 checkbox。
- pytest 增加 `invalid checkbox -> 422` 和 `valid checkbox -> 200`。

验收：

- `{"agree": true}` 返回 `200`。
- `{"agree": "not_bool"}` 返回 `422`。
